# G0.1 脱敏探针日志

## 安全说明

- 本日志不记录账号、手机号、身份证、会话、应用 ID、插件 ID、Trace ID 或真实密钥。
- API 鉴权仅使用无访问能力的虚拟值 `g01-dummy-token`。
- 所有赛事平台对象均为草稿；没有发布、付费、上传教材或创建发布渠道。

## 探针结果

| 探针 | 输入 | 观察结果 | 结论 |
| --- | --- | --- | --- |
| 外部 HTTPS | `GET https://httpbin.org/anything` | 返回方法、URL 和请求 Header | 通过 |
| Header 传递 | `X-Probe-Token: g01-dummy-token` | 回显响应包含同一虚拟 Header | 通过 |

| Python 单次观察 | 固定均值函数 | 页面操作到读取结果约 2.15 秒 | 仅证明托管执行可用，不是性能基准 |
| 草稿状态 | 应用发布页面 | 显示“待发布”，发布渠道为空 | 通过，未发布 |

## 管理端前端错误摘要

浏览器控制台曾出现以下类别的管理端错误：

1. Monaco 编辑器外部模块加载异常；
2. Vue 组件访问未定义属性；
3. 明文 HTTP 环境不支持麦克风、摄像头和屏幕捕获。

这些错误没有阻止本轮 API 与固定 Python 探针成功，但会影响编辑稳定性。G3 必须验证错误后重登
能恢复配置；作品不依赖语音、视频或屏幕共享。
