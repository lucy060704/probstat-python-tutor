## 关键设计决定

1. **理由必须覆盖多个教学目标。** 概念题分别要求条件分母、交集和独立性证据；Python 题分别
   要求种子用途和有限模拟含义；解释题分别要求理论边界、有限比例和次数趋势。只复述答案、
   名词或无关领域的“随机误差”均为证据不足。
2. **否定保护属于通用证据机制。** 支持短语使用分句内前置和后置否定窗口；单字“没/不”只在
   紧邻目标短语时生效，避免把“不过样本越大……”误当成否定，同时识别“这一说法不对”。
3. **表面正确答案不能覆盖反向理由。** 条件分母错误、把交集非零当互斥或独立、把有限模拟写成
   固定无误差值、宣称误差每次下降等都会生成可追溯的 `contradicts` finding。
4. **代码等价性以同一数据依赖为边界。** 接受 `draws.mean()`、`np.mean(draws)`、
   `draws.sum()/1000` 和 `draws.sum()/len(draws)`；`len` 必须解析到与分子完全相同的已生成
   数组。错误数组、重绑定、重复随机调用、错误大小写、参数或种子均拒绝。
5. **学生代码永不执行。** 判分仅使用有长度、节点数和深度上限的 `ast.parse` 结果；危险调用
   仍走原有安全拒绝路径。
