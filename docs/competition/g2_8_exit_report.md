## 关键设计决定

1. **把显著性、效应量和实际意义分开。** 题目要求学习者分别说明
   p 值和阈值、绝对百分点差、相对提升、置信区间和事先业务阈值，
   不允许用“显著”替代“重要”。
2. **p 值采用条件化、可观察的证据合同。** 必须在 H0 和检验条件下解释
   当前或更极端数据；明确拒绝/未拒绝的决策语句，不把 p 值当作假设真伪
   的概率或效应大小。
3. **A/B 设计边界进入确定性诊断。** 多重比较、事后挑选、自选分组、
   差异流失、内部因果效度和外部适用性都有独立的可观察证据与误区标签。
4. **学习者 Python 从不执行。** 系统只用 `ast.parse` 检查
   `stats.ttest_ind`/`scipy.stats.ttest_ind`、两个系统数组、Welch 关键字、
   双侧参数和 `.pvalue` 结果连通性。
5. **Python 结构保持封闭白名单。** 同组复用、等方差检验、单侧检验、
   误取 `statistic`、追加参数、路径后缀、重绑定、控制流、导入和危险调用均拒绝。
6. **中文诊断只做可审计的有界语义。** 支持分组全满足证据、稳定同义原子、
   否定保护、末句反转和整段撤回；大模型可以润色解释，但不能改分。
7. **合成数据不伪装真实证据。** 数据只用于可重现教学，不含个人信息，
   不代表真实学生、用户或线上实验结果。
