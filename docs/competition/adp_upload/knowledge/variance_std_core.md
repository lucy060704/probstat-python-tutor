# 方差与标准差基础

> 团队原创课程资料｜资料标识：variance_std_core｜版本：0.1.0｜知识点：variance_std

## 学习目标

- 理解方差和标准差用于描述数据围绕中心的离散程度。
- 区分总体口径与样本口径，并理解自由度参数对计算结果的影响。
- 能结合单位和数据情境解释标准差，而不是只比较数字大小。

## 前置知识

- 理解算术均值以及观测值与均值之差。
- 能进行平方、开平方和求和运算。

## 概念解释

只知道数据中心还不够。两组数据可能具有相同均值，却表现出完全不同的波动。 方差和标准差通过考察观测值偏离均值的程度来补充这部分信息。

方差使用平方离差，因此较大的偏离会获得更大的权重。标准差是方差的平方根， 它与原始数据具有相同单位，通常更容易结合实际情境解释。

总体方差描述手中完整总体的离散程度；样本方差用于从有限样本估计总体波动。 两种口径的分母不同，分析时必须说明使用了哪一种。

## 公式与方法

### 总体方差

- 表达式：`σ² = Σ(xᵢ - μ)² / N`
- 含义：总体方差是全部观测值平方离差的平均。
- 符号说明：
  - `sigma_squared`：总体方差
  - `x_i`：总体中的第 i 个观测值
  - `mu`：总体均值
  - `N`：总体观测个数
- 使用前提：
  - 手中的数据被视为要描述的完整总体。
  - 各观测值使用一致的测量单位。
- 注意事项：
  - 方差单位是原始单位的平方，不能直接当作原始量解释。
  - 平方会放大极端偏离的影响。

### 样本方差与样本标准差

- 表达式：`s² = Σ(xᵢ - x̄)² / (n - 1)，s = √s²`
- 含义：样本方差使用 n-1 作为分母，标准差再对方差开平方以恢复原始单位。
- 符号说明：
  - `s_squared`：样本方差
  - `s`：样本标准差
  - `x_bar`：样本均值
  - `n`：样本观测个数
- 使用前提：
  - 数据被作为总体中的一个样本分析。
  - 样本中的观测和抽样过程适合用于描述目标总体。
- 注意事项：
  - 样本量太小时，离散程度估计可能不稳定。
  - 不能把方差数值直接当成标准差数值。

## Python联系

### pandas：Series.var 和 Series.std

- 用途：分别计算一列数据的样本方差和样本标准差。
- 输入要求：输入应为数值型 Series，并明确缺失值、数据单位和样本定义。
- 解释提醒：Pandas 默认使用样本口径；如果研究问题需要总体口径，应明确调整自由度参数。

### NumPy：numpy.var 和 numpy.std

- 用途：对数组计算方差或标准差，并通过轴参数控制计算方向。
- 输入要求：需要主动确认 ddof、axis、数组形状和缺失值处理方式。
- 解释提醒：NumPy 的默认自由度与 Pandas 默认值不同，不能只凭函数名称假定口径一致。

## 数据解释原则

- 比较标准差前先确认各组数据使用相同单位、相似测量尺度和一致计算口径。
- 标准差较小通常表示观测值更集中于均值附近，但不能据此判断平均水平更高。
- 标准差较大表示波动更明显，不自动表示数据质量差，也不说明变化由某个因素造成。
- 对明显偏态或含极端值的数据，应同时查看分位数、图形和稳健的离散指标。

## 常见误区

### 误区1：两组数据的均值相同，所以它们的方差也相同。

- 为什么不正确：均值只描述中心，方差取决于各观测值距离均值的程度。
- 更好的追问：两组观测值到各自均值的距离分布是否相似？

### 误区2：标准差越大表示数据越稳定。

- 为什么不正确：标准差越大通常表示观测值围绕均值的波动越大。
- 更好的追问：“稳定”在当前情境中是否意味着观测值更集中？

### 误区3：方差和标准差只是同一个结果的两种名称。

- 为什么不正确：标准差是方差的平方根，两者数值和单位都不同。
- 更好的追问：当前输出的单位与原始数据单位相同，还是原始单位的平方？

## 反思问题

- 如果所有观测值都相同，离均值的距离会呈现什么特征？
- 为什么比较两个标准差之前需要先确认数据单位和计算口径？
- 当标准差受到极端值影响时，还可以查看哪些图形或统计摘要？

## 小结

- 方差和标准差描述数据围绕均值的离散程度。
- 标准差与原始数据单位一致，方差的单位是原始单位的平方。
- Python 函数的自由度默认值可能不同，必须明确总体或样本口径后再解释结果。
