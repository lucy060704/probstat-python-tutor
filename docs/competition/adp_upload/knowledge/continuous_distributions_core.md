# 连续分布、密度与累计概率

## 学习目标

- 区分连续概率密度、精确点概率和区间概率。
- 解释正态分布的参数与数学支持集，并检查其作为现实模型的边界。
- 根据问题选择 PDF、CDF 或随机抽样 API。

## 前置知识

- 理解随机变量、概率和区间的基本含义。
- 能计算一个累计概率减去另一个累计概率。

## 概念解释

连续随机变量在区间中取值。理想未舍入的连续模型对单个精确点分配的概率为 0； 正概率来自一个具有宽度的区间。现实记录为某个整数时，常常代表舍入区间而非数学上的精确点。

概率密度函数 PDF 描述概率在取值轴附近的集中程度。密度值可以大于 1，且通常带有 “每单位测量值”的量纲，因此不能直接解释成点概率或百分比。

累积分布函数 CDF 定义为 F(x)=P(X≤x)。连续区间概率可由上端点 CDF 减去 下端点 CDF 得到；是否包含端点在理想连续模型中不改变结果。

正态分布由中心参数 μ 和正的尺度参数 σ 决定，数学支持集为全部实数。 对时间、长度等现实非负变量使用正态模型时，应检查负值尾部是否可以忽略，不能把模型选择当成拟合证明。

## 公式与方法

### 正态概率密度

- 表达式：`f(x) = exp(-(x-μ)^2/(2σ^2)) / (σ√(2π))`
- 含义：给出 x 附近的概率密度高度，区间下的面积才是概率。
- 符号说明：
  - `mu`：分布中心
  - `sigma`：正的标准差尺度，不是方差
  - `x`：支持集中的实数取值
- 使用前提：
  - 采用参数为 μ 和 σ 的正态概率模型。
- 注意事项：
  - f(x) 不是 P(X=x)。

### 连续区间概率

- 表达式：`P(a≤X≤b)=F(b)-F(a)`
- 含义：从截至上端点的累计概率中减去截至下端点的累计概率。
- 符号说明：
  - `F`：累积分布函数
  - `a`：查询区间下端点
  - `b`：查询区间上端点
- 使用前提：
  - a 不大于 b，且两个 CDF 值来自同一分布和参数。
- 注意事项：
  - 不能用两个 PDF 高度的差代替曲线下面积。

## Python联系

### SciPy：scipy.stats.norm.pdf

- 用途：计算正态模型在给定取值处的概率密度。
- 输入要求：loc 对应 μ，scale 对应正的 σ。
- 解释提醒：输出是密度，不是恰好等于该值的概率。

### SciPy：scipy.stats.norm.cdf

- 用途：计算不超过给定取值的累计概率，并通过端点作差得到区间概率。
- 输入要求：两个端点必须使用相同 loc 和 scale。
- 解释提醒：单个上端点 CDF 通常还包含查询区间下界以下的概率。

### SciPy：scipy.stats 中连续分布的 rvs

- 用途：按给定连续模型随机生成样本。
- 输入要求：记录参数、样本量和随机状态。
- 解释提醒：随机样本不是密度或理论区间概率，也不验证现实数据服从该分布。

## 数据解释原则

- 先区分问题询问的是密度高度、累计概率、区间概率还是随机生成。
- 连续区间概率使用相同模型下两个 CDF 值作差，不把 PDF 高度当作概率质量。
- 报告正态模型时写明 μ、σ、单位和支持集边界，并检查现实变量的可取范围。
- 若观测值经过四舍五入或分箱，应把记录值解释为区间，而不是精确点事件。

## 常见误区

### 误区1：PDF 在某点的值就是随机变量恰好等于该点的概率。

- 为什么不正确：连续模型的精确点概率为 0，PDF 是单位取值长度上的密度高度。
- 更好的追问：我需要一个点的密度，还是一段有宽度区间下的面积？

### 误区2：区间概率等于两个端点 PDF 值之差。

- 为什么不正确：PDF 高度之差不是曲线下面积，区间概率可用 CDF 作差。
- 更好的追问：截至上端点的累计概率中还包含了哪些下界以下的结果？

### 误区3：现实变量非负，所以正态分布的数学支持集也自动截断为非负值。

- 为什么不正确：普通正态分布形式上支持全部实数，现实边界是评估模型适用性的额外条件。
- 更好的追问：模型允许哪些取值，现实变量允许哪些取值，两者差异是否可接受？

## 反思问题

- 为什么连续模型中的精确点概率为 0，但一个舍入记录的概率可以大于 0？
- PDF、CDF 和区间概率分别具有怎样的单位和含义？
- 用正态分布描述非负变量时，需要额外检查什么？

## 小结

- PDF 是密度，连续精确点概率为 0，区间概率由面积或 CDF 作差得到。
- 正态分布的 μ 控制中心、σ 控制尺度，数学支持集为全部实数。
- 使用分布 API 是执行模型计算，不是对现实分布适配性的证明。
