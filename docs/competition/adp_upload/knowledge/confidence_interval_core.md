# 置信区间构造、长期覆盖与解释边界

> 团队原创课程资料｜资料标识：confidence_interval_core｜版本：0.2.0｜知识点：confidence_interval

## 学习目标

- 理解置信区间由点估计、不确定性尺度和临界值共同构成。
- 能从重复抽样和长期覆盖率角度解释置信水平。
- 能区分区间估计、参数概率和原始数据覆盖范围。
- 能区分误差界限、完整区间宽度以及样本量和置信水平的作用。
- 能说明窄区间不能修复抽样或测量偏差。

## 前置知识

- 理解样本均值、标准差和标准误。
- 能进行加减法、乘法并理解区间上下限。

## 概念解释

点估计用一个数概括未知参数，但单个数字没有直接展示抽样不确定性。 置信区间在点估计两侧加入误差范围，用一段区间表达与数据和方法相容的参数范围。

频率学派的置信水平描述构造方法的长期表现：如果在相同条件下重复抽样并重复构造区间， 一定比例的区间会覆盖真实参数。参数在每次研究中被视为固定而未知。

区间宽度受到标准误、置信水平、样本量和模型条件影响。 更高置信水平通常需要更宽区间；更大样本量在其他条件相近时通常会减小标准误。

区间的代数宽度呈现所用模型下的随机精度，不是数据质量证书。便利抽样、无应答、聚类依赖、 测量偏移或错误模型都可能让一个很窄的区间围绕错误中心，或使实际覆盖率偏离名义水平。

## 公式与方法

### 常见双侧置信区间结构

- 表达式：`点估计 ± 临界值 × 标准误`
- 含义：临界值与标准误的乘积形成误差范围，再从点估计向两个方向扩展。
- 符号说明：
  - `point_estimate`：根据样本得到的参数估计值
  - `critical_value`：由置信水平和参考分布决定的临界值
  - `standard_error`：点估计的抽样波动尺度
- 使用前提：
  - 点估计的抽样分布能够由所选参考分布合理近似。
  - 标准误计算与抽样设计和统计模型一致。
  - 数据收集过程满足所用区间方法的关键条件。
- 注意事项：
  - 临界值不是所有置信水平和所有问题都相同。
  - 区间公式不能弥补严重的抽样偏差或模型设定错误。
  - 标准正态双侧区间中的常见临界值只适用于相应置信水平和参考分布；总体方差未知等情形可能需要 t 分布或其他方法。

### 误差界限与完整宽度

- 表达式：`半宽=临界值×标准误；完整宽度=2×临界值×标准误`
- 含义：同一对称区间的完整宽度是误差界限的两倍。
- 符号说明：
  - `margin`：点估计到任一端点的距离
  - `width`：上限减下限
  - `critical_value`：由置信水平和参考分布决定的临界值
  - `standard_error`：估计量的抽样波动尺度
- 使用前提：
  - 使用以点估计为中心的对称区间结构。
  - 临界值和标准误与目标参数及设计相匹配。
- 注意事项：
  - 只比较置信水平而忽略样本量和变异程度，不能判断两个不同研究谁更宽。
  - 样本量按平方根影响常见均值标准误，不按样本量本身线性缩放。

### 置信水平的长期覆盖含义

- 表达式：`覆盖率 = 长期重复过程中包含真实参数的区间比例`
- 含义：置信水平是区间构造程序的性质，而不是对单个固定参数重新赋予随机概率。
- 符号说明：
  - `coverage_rate`：同一构造方法在重复抽样中的长期覆盖比例
  - `parameter`：固定但未知的总体参数
- 使用前提：
  - 每次重复都遵循相同的数据生成和区间构造方法。
  - 所讨论的覆盖率是长期频率意义上的比例。
- 注意事项：
  - 不能把置信区间解释成原始数据中某个比例必定位于区间内。
  - 区间外的参数值不是逻辑上绝对不可能，只是与当前数据和方法较不相容。

## Python联系

### NumPy：数组加减法与临界值乘标准误

- 用途：根据已确认的点估计、临界值和标准误计算区间上下限。
- 输入要求：输入前应先确认标准误口径、临界值来源和上下限顺序。
- 解释提醒：数组运算只完成代数步骤，不会检查抽样条件或区间方法是否合适。

### SciPy：scipy.stats 中分布的区间或分位数函数

- 用途：根据参考分布和置信水平获得临界值或构造区间。
- 输入要求：应明确使用的分布、自由度、位置参数和尺度参数。
- 解释提醒：不同函数对 scale 的定义可能不同，不能把样本标准差直接当成均值标准误。

### pandas：DataFrame 或 Series 的描述性统计配合 SciPy

- 用途：先整理样本量、均值和标准差，再把明确的统计量传入区间计算。
- 输入要求：需要先处理缺失值、分组方式和数据类型。
- 解释提醒：分组后每组样本量不同，标准误和区间宽度也可能不同。

## 数据解释原则

- 解释置信区间时同时说明参数对象、置信水平、区间构造方法和数据来源。
- 不把单次区间描述为“参数有某个概率落在里面”，应从方法的长期覆盖性质说明。
- 不把参数区间当作个体观测值的正常范围，也不把它当作未来单个观测的预测区间。
- 比较区间宽度时同时检查样本量、变异程度、置信水平和使用的方法。
- 报告名义置信水平时同时披露抽样设计和关键模型条件，不把名义覆盖率写成无条件保证。

## 常见误区

### 误区1：置信水平表示固定参数在本次区间内的概率。

- 为什么不正确：在频率学派框架中，参数固定而区间随样本变化；置信水平描述构造方法的长期覆盖率。
- 更好的追问：如果重复进行同样的抽样和区间构造，哪些对象会随样本改变？

### 误区2：区间之外的参数值被证明绝对不可能。

- 为什么不正确：区间表达当前数据和方法下相容性较高的范围，不是逻辑上的绝对边界。
- 更好的追问：区间能够排除到什么程度，是否还受到模型条件和抽样误差影响？

### 误区3：置信区间包含的是大部分原始数据。

- 为什么不正确：参数置信区间针对总体参数，原始观测范围和预测区间是不同问题。
- 更好的追问：当前区间估计的对象是总体参数、个体观测还是未来预测值？

### 误区4：样本量增加四倍会让常见均值区间宽度缩为四分之一。

- 为什么不正确：在其他条件相同时，均值标准误按样本量平方根缩放，因此样本量四倍通常使宽度约减半。
- 更好的追问：区间宽度公式中的样本量位于平方根内还是平方根外？

### 误区5：更窄的区间证明抽样无偏且一定实现名义覆盖率。

- 为什么不正确：宽度主要反映所用模型下的随机波动；系统偏差可能移动区间中心并破坏实际覆盖。
- 更好的追问：数据收集机制是否让估计值围绕正确目标，所用标准误是否反映真实依赖结构？

## 反思问题

- 为什么提高置信水平通常会改变区间宽度？
- 两项研究给出宽度不同的区间时，应检查哪些数据和方法条件？
- 如何向初学者区分参数置信区间与未来观测的预测区间？
- 为什么一个很窄的便利样本区间仍可能具有很差的实际覆盖？

## 小结

- 置信区间把点估计与抽样不确定性结合起来。
- 置信水平描述区间构造方法在重复抽样中的长期覆盖表现。
- 区间宽度由临界值和标准误共同决定；更窄不等于无偏或覆盖有效。
- Python 可以完成区间计算，但正确解释仍依赖参数对象、抽样条件、标准误和参考分布。
