# 数据加载、缺失值与数据质量

> 团队原创课程资料｜资料标识：data_quality_core｜版本：0.1.0｜知识点：data_quality

## 学习目标

- 区分缺失值、合法的零、可疑异常值、无效格式和重复记录。
- 在汇总统计前检查字段类型、单位、范围、唯一标识和缺失情况。
- 说明删行、填补和类型转换怎样改变分析对象或样本构成。
- 解读 pandas 给出的数据质量事实，同时保留情境判断和处理记录。

## 前置知识

- 知道一行通常代表一个观测单位，一列代表一个字段。
- 能区分数值、文本和布尔值等基本数据类型。
- 能计算简单比例，并理解分子和分母的含义。

## 概念解释

文件成功读入只说明解析流程没有立即失败，不代表每个字段都适合分析。开始计算前，应先写清 一行代表谁或什么、字段的类型和单位、合法范围、唯一性以及允许的缺失表示。

缺失表示某个本应观察的值没有被记录；真实的零则是已经观察到的数值。可疑的极端值可能是 录入错误，也可能是真实事件。三者需要不同证据，不能由一个通用函数自动互换。

删除或填补不是中性的清洁动作。删行会改变样本量和群体构成；填补会改变分布、均值、方差 或变量关系。处理前应先比较缺失在不同群体中的分布，并记录决策依据。

数据质量判断同时包含技术事实和分析情境。Python 能发现缺失数量、重复候选、类型和范围， 但不能仅凭这些事实判断一条记录是否应删除，也不能证明处理后的样本仍代表目标总体。

## 公式与方法

### 字段缺失率

- 表达式：`missing_rate = missing_cells / denominator_records`
- 含义：缺失率描述一个字段中没有观察到值的相对数量。
- 符号说明：
  - `missing_cells`：目标字段中被规则识别为缺失的单元格数量
  - `denominator_records`：该字段按分析单位本应具有的记录数量
- 使用前提：
  - 已经明确哪些标记代表缺失。
  - 分母与当前分析单位一致。
- 注意事项：
  - 缺失率低不等于处理后一定无偏。
  - 总体缺失率可能掩盖某个群体中的集中缺失。

### 完整案例保留率

- 表达式：`retention_rate = complete_records / original_records`
- 含义：保留率用于审计完整案例分析改变了多少记录。
- 符号说明：
  - `complete_records`：按当前分析所需字段均有记录的行数
  - `original_records`：删除或筛选前的原始行数
- 使用前提：
  - 原始行数和完整行数采用相同分析单位。
  - 已明确哪些字段是当前分析必需的。
- 注意事项：
  - 较高保留率不能单独证明保留样本有代表性。
  - 还应报告删行前后的关键分组构成。

## Python联系

### pandas：pandas.read_csv

- 用途：从表格文件建立 DataFrame，并显式指定需要的缺失标记、列类型或解析参数。
- 输入要求：先确认分隔符、表头、编码、缺失标记和日期或数值格式。
- 解释提醒：没有抛出异常只表示文件可解析，不代表字段含义、单位或取值都有效。

### pandas：Series.isna 和 DataFrame.isna

- 用途：生成缺失布尔掩码，可按列或分组统计缺失事实。
- 输入要求：先核对源文件中的空白、特殊文本和哨兵值如何转换为缺失。
- 解释提醒：isna 不会把业务上无效但技术上非空的数值自动识别为异常。

### pandas：DataFrame.duplicated

- 用途：根据指定字段标记重复候选，辅助核对唯一标识或重复测量。
- 输入要求：必须先说明哪些列共同定义一条记录的唯一性。
- 解释提醒：重复 ID 可能是错误，也可能代表合法的多次测量，不能看到 True 就直接删除。

### pandas：pandas.to_numeric

- 用途：把可解析文本转换为数值，并发现混杂格式。
- 输入要求：先确认单位和小数符号；若使用 errors="coerce"，应统计新产生的缺失。
- 解释提醒：强制转换为缺失只是暴露解析失败，不等于已经修复源数据。

### pandas：DataFrame.dropna 和 DataFrame.fillna

- 用途：在已有、可说明的处理方案下执行删行或填补。
- 输入要求：明确目标列、轴、阈值、填补依据和处理前后的审计指标。
- 解释提醒：函数会改变数据，但不会判断处理后是否无偏或适合推广到目标总体。

## 数据解释原则

- 先报告一行的分析单位、原始样本量、字段单位和有效范围。
- 同时查看整体缺失率和关键群体的分组缺失率，避免总比例掩盖集中缺失。
- 对可疑极端值追溯来源、测量单位和录入过程；在核验前保留原始值和待核验标记。
- 若删行或填补，记录处理规则、受影响记录数、处理前后分组构成以及结论适用范围。
- 不能仅根据一张有缺失的表判断缺失机制或偏差方向；证据不足时应明确限制。

## 常见误区

### 误区1：数值 0 一定表示缺失。

- 为什么不正确：零可能是合法且有实际含义的观测；是否缺失取决于字段规则和源数据标记。
- 更好的追问：这个字段的合法范围和缺失标记分别是什么？

### 误区2：文件没有报错就证明数据有效。

- 为什么不正确：解析成功不能验证单位、范围、唯一性、业务含义和样本代表性。
- 更好的追问：读入后还需要核对哪些字段约束和分组分布？

### 误区3：所有重复 ID 都能直接删除。

- 为什么不正确：同一对象可能有合法的重复测量，唯一性需要由分析单位和组合键决定。
- 更好的追问：一行代表一次测量还是一个对象，哪些字段共同定义唯一记录？

### 误区4：删除含缺失的行一定不会影响结论。

- 为什么不正确：如果缺失集中在某个群体，完整案例的构成可能与目标总体不同。
- 更好的追问：删除前后各群体的数量和比例怎样变化？

### 误区5：用均值填补只是在补空白，不会改变分析。

- 为什么不正确：均值填补会压缩波动，并可能改变相关关系和不确定性估计。
- 更好的追问：填补对分布、方差、变量关系和结论限制有什么影响？

## 反思问题

- 如果一个字段整体只缺失少量记录，但这些记录都来自同一群体，应该补充检查什么？
- 一个极端值需要哪些来源证据，才能决定保留、修正或剔除？
- 使用 errors="coerce" 后，怎样区分原始缺失和转换新产生的缺失？
- 你的处理日志至少应记录哪些数据规模、分组和规则信息？

## 小结

- 数据可读取不等于数据可直接分析；字段规则和分析单位必须先明确。
- 缺失、合法零值、异常值和重复候选需要不同证据，不能自动互换。
- Python 提供可观察事实，处理决策和代表性解释仍需情境依据。
- 所有删行、填补和类型转换都应记录处理前后的样本量、群体构成和结论边界。
