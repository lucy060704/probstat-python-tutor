# 抽样与标准误基础

> 团队原创课程资料｜资料标识：sampling_standard_error_core｜版本：0.2.0｜知识点：sampling_standard_error

## 学习目标

- 区分样本、总体、样本统计量和抽样分布。
- 理解标准差描述个体差异，而标准误描述统计量的抽样波动。
- 能说明样本量、样本标准差与均值标准误之间的关系。
- 区分随机波动、系统偏差和均方误差，避免把精度等同于准确性。

## 前置知识

- 理解均值、方差和样本标准差。
- 能进行平方根运算，并理解分母增大通常会使比值减小。

## 概念解释

抽样是从目标总体中选取一部分观测来了解总体。即使抽样方法相同， 不同随机样本得到的样本均值也通常不会完全相同，这种变化形成样本均值的抽样分布。

标准差描述同一个样本中个体观测值的差异。标准误描述如果重复抽样， 某个统计量会在不同样本之间波动多少。两者回答的问题不同。

从定义上说，标准误是估计量抽样分布的标准差。总体标准差已知时，均值标准误可写成 σ/√n；实际分析通常用样本标准差 s 代替 σ，得到估计标准误 s/√n。

在抽样条件和总体变异程度近似不变时，增加样本量通常会减小均值的标准误。 这表示样本均值作为总体均值估计值时通常更精确，但不保证样本没有偏差。

## 公式与方法

### 样本均值的估计标准误

- 表达式：`SE(x̄) = s / √n`
- 含义：用样本标准差估计总体波动后，再除以样本量的平方根，得到样本均值的典型抽样波动尺度。
- 符号说明：
  - `SE_x_bar`：样本均值的估计标准误
  - `s`：样本标准差
  - `n`：样本量
- 使用前提：
  - 样本来自适合研究目标的抽样过程。
  - 观测之间的依赖结构不会让简单公式失效。
  - 样本标准差能够合理反映目标总体的变异程度。
  - 简单公式假定独立观测；聚类、重复测量或较高比例无放回抽样可能需要设计修正。
- 注意事项：
  - 分母是样本量的平方根，不是样本量本身。
  - 更小的标准误不代表个体观测值之间的差异更小。
  - ddof=1 规定了样本标准差的估计口径，不是对所有设计都充分的修正。

### 样本量变化与标准误比例

- 表达式：`在变异程度近似不变时，SE 与 1/√n 成正比`
- 含义：样本量增加会降低抽样波动，但降低速度由平方根关系决定。
- 符号说明：
  - `SE`：统计量的标准误
  - `n`：样本量
- 使用前提：
  - 比较的研究具有近似相同的变异程度和抽样条件。
  - 使用的是同一种统计量和一致的标准误定义。
- 注意事项：
  - 不能忽略标准差同时变化的情况。
  - 增加样本量不能自动修复选择偏差、测量偏差或混杂问题。

### 偏差、方差与均方误差的关系

- 表达式：`MSE(θ̂) = Var(θ̂) + Bias(θ̂)²`
- 含义：标准误主要对应随机波动尺度；总体准确性还取决于系统偏差。
- 符号说明：
  - `MSE`：估计量相对目标参数的平均平方误差
  - `Var`：估计量在重复抽样中的方差
  - `Bias`：估计量平均位置与目标参数的系统偏移
- 使用前提：
  - 目标参数和估计量定义明确。
  - 比较使用相同的数据生成与抽样设计。
- 注意事项：
  - 小标准误只能说明随机部分较小，不能单独推出偏差为零。
  - 固定测量偏移可能几乎不改变标准误，却持续移动估计量中心。

## Python联系

### NumPy：numpy.std、numpy.sqrt 和 len

- 用途：先按样本口径计算标准差，再根据样本量计算均值的估计标准误。
- 输入要求：输入应是一维数值样本，并明确自由度、缺失值和观测独立性。
- 解释提醒：代码算出的标准误只反映公式所描述的抽样波动，不会检查抽样是否有偏。

### pandas：Series.sem

- 用途：计算 Series 中均值的估计标准误。
- 输入要求：需要确认 Series 的有效观测数、缺失值规则和自由度设置。
- 解释提醒：便捷函数不会替代对抽样设计和观测依赖性的判断。

### SciPy：scipy.stats.sem

- 用途：在科学计算流程中计算标准误，并允许明确缺失值和自由度选项。
- 输入要求：应检查输入数组维度以及 axis、ddof 和 nan_policy 等参数。
- 解释提醒：参数设置不同会产生不同口径，报告结果时应保留这些设定。

## 数据解释原则

- 看到“更精确”时，先确认讨论的是样本统计量的重复抽样波动，而不是个体数据更集中。
- 比较两个标准误时，应同时检查样本量、样本标准差、抽样方法和数据依赖结构。
- 标准误较小表示统计量在重复抽样中通常更稳定，但不等于估计一定接近真实参数。
- 报告标准误时说明它对应哪个统计量，例如均值、比例或回归系数。
- 缺失值会改变有效样本量；聚类和重复测量会改变有效独立信息量，不能只读取数组长度。

## 常见误区

### 误区1：标准差和标准误都是“数据有多分散”，可以互换。

- 为什么不正确：标准差描述个体观测值，标准误描述统计量在重复抽样中的波动。
- 更好的追问：当前要描述的是样本内部个体差异，还是样本统计量的不确定性？

### 误区2：样本量扩大多少倍，标准误就按相同倍数缩小。

- 为什么不正确：常见均值标准误公式包含样本量的平方根，变化不是简单的线性倒数。
- 更好的追问：样本量变化后，它的平方根改变了多少？

### 误区3：标准误很小就证明研究没有偏差。

- 为什么不正确：标准误主要描述随机抽样波动，系统性的选择偏差或测量偏差可能仍然存在。
- 更好的追问：除随机误差外，抽样和测量过程还可能引入哪些系统性问题？

### 误区4：样本量就是有效独立信息量，任何数据都能直接套用 s/√n。

- 为什么不正确：相关观测、整群抽样、重复测量和无放回高抽样比例会改变抽样方差。
- 更好的追问：观测是否独立，抽样设计是否要求有限总体、聚类或其他修正？

## 反思问题

- 为什么同一总体的两个随机样本可能得到不同的样本均值？
- 如果样本量增加但样本标准差也明显增加，能否只根据样本量判断标准误变化？
- 一项研究的标准误很小，还需要检查哪些抽样质量问题？
- 同一个固定偏移加到每个读数后，样本标准差、标准误和样本均值分别怎样变化？

## 小结

- 标准差描述个体差异，标准误描述统计量的抽样波动。
- 均值标准误通常与样本标准差成正比，与样本量平方根成反比。
- 增大样本量可以降低随机波动，但不能自动消除抽样偏差或测量问题。
- 简单标准误公式依赖抽样设计；精度、偏差和准确性必须分开报告。
