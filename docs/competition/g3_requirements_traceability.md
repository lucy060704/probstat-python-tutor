# G1–G3 需求—证据追踪表

## 1. 审计边界

本表把比赛原始要求、作品方向和 G1–G3 本地工程目标逐项对应。结论只证明本地工程可以复现，
不把教师签字、真实学生试点、比赛视频、平台适配或获奖概率包装成已经完成。

作品方向保持为：**知迹·StatPy——“概率统计 × Python 数据分析”跨学科启发式学习与诊断
智能体**，面向正在学习《概率论与数理统计》和《Python 数据分析》相关课程的高校本科生，
并为教师/助教提供匿名汇总。

## 4. 不能由工程测试代替的证据

- 教师逐题/逐单元签字审核，以及教师教材使用许可的可归档证明；
- 10–15 名真实学生的知情同意、匿名试点和任务完成率；
- Windows 11 实机双击启动、显示和完整旅程；
- 正式申报表、比赛版设计说明书和不超过 5 分钟的视频；
- 本地版本冻结后的 ADP 适配、正式发布和最终提交回执。

这些项目没有完成前，`competition_submission_ready` 必须保持 `false`。
