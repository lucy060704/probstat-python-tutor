## 关键设计决定

1. **保留冻结题合同，用新题补深度。** 三道现有置信区间题保留 ID、答案和容差；新增
   Bias/Var/MSE 比较和“窄区间不等于无偏”解释题，避免为扩题破坏历史基线。
2. **把频率学派边界做成可观察证据。** 覆盖率题必须区分固定未知参数与随样本变化的
   区间，并明确长期约 95% 覆盖不是单次参数概率，也不是 100 次必定恰好 95 次。
3. **偏差、方差和 MSE 分开判。** 学习者需提供 `Bias=E(T)-theta`、`Var=SD^2`、
   `MSE=Var+Bias^2` 的具体证据；无偏不代表每次准确，也不保证 MSE 最小。
4. **Python 答案从不执行。** 判题仅用 `ast.parse` 检查区间端点的计算连通性；支持已
   审核的向量式、显式端点式、浮点偏移和简单别名链，拒绝反序、双加、漏临界值、错用
   标准差、断开结果、额外参数和危险调用。
5. **分步变量采用封闭白名单。** 在结果前只允许直线的简单赋值；`AugAssign`、海象运算符、
   `del`、导入、循环、函数定义、方法篡改和控制流均拒绝，避免重绑定或副作用绕过。
6. **自然中文只做有界归一化。** 确定性证据层统一受控的百分数、术语和同义短语；不改数值答案或
   AST 合同，不允许大模型凭语义修改分数。误区使用稳定的“错误命题原子”检测，不依赖整句标点完全一致。
7. **窄区间不能为抽样设计背书。** 四倍样本量使常见均值标准误约减半而非四分之一；
   更高置信水平通常需要更宽区间；增加便利样本规模只能减少随机波动，不能消除系统选择偏差。
