## 关键设计决定

1. **兼容旧题，同时增加深度题。** 原标准误题保留冻结评测需要的答案合同；另增 CLT 和固定
   偏差题，避免为了扩题破坏既有开发集与 v0.1 基线。
2. **CLT 理由必须逐项举证。** 学习者需说明讨论对象是样本均值的抽样分布、抽样独立、总体
   方差有限、样本量足够、中心仍为总体均值、标准误为 `σ/√n`，并区分总体原始分布与抽样
   分布；只写“样本量大所以正态”不能通过。
3. **随机波动与系统偏差分开判。** 精度题检查同样本标准差下较大样本量带来较小标准误；
   偏差题进一步要求指出固定测量偏移不会因样本量增加而自动消失，较小标准误也不代表无偏。
4. **Python 答案从不执行。** 判题只用 `ast.parse` 检查样本标准差、`ddof=1`、样本量和平方根
   的结果连通性；允许 `len`、`shape[0]` 和 `np.size` 等审核过的等价写法，拒绝 `/n`、方差、
   原始标准差、错误轴、额外参数、重绑定、断开结果和危险调用。
5. **自然中文采用有界归一化。** 只在确定性证据匹配层统一“平均数/均值”“根号/√”“除以/÷”
   等受控同义表达；数字判题和 AST 合同不受影响，大模型不能凭语义猜测修改分数。
6. **否定和撤回具有方向。** “不能说样本越大偏差越大”等保护句不会触发误区；整段理由被
   否定时不能得分；明确撤回旧说法后完整重述可重新判定。
7. **知识卡不泄露正式题。** 两张知识卡仅保存通用定义、公式、边界和教学示例，manifest 使用
   SHA-256 校验，正式题数字与答案不进入检索卡。
