## 关键设计决定

1. **三个概率口径必须分别举证。** 联合、条件和边缘概率各有独立证据组；只有比较条件比例与
   边缘比例后才能支持独立性结论，不能只凭选项字母得分。
2. **相关解释同时检查缩放、量纲和研究设计。** 协方差随单位缩放并保留乘积量纲；相关系数
   在正比例换算下不变且无量纲；观察性样本关系不能被写成个体必然规律或因果结论。
3. **命名聚合使用封闭 AST 合同。** 允许 tuple、`pd/pandas.NamedAgg`、简单常量变量、
   `by=["group"]`、`as_index=True` 以及布尔 `sort` 等价写法；拒绝错误键、列、函数、输出名、
   额外列、list 伪聚合、后续 `reset_index`、断开结果和 `df` 重绑定。
4. **学习者代码从不运行。** 判题只使用 `ast.parse` 和有界结构提取；专项测试把
   `pandas.DataFrame.groupby`、`eval` 和 `exec` 替换为一旦调用就失败的函数，判题仍能完成。
5. **危险别名保守阻断。** 除直接危险调用外，还识别简单赋值链、`builtins` 导入别名、tuple
   解包、walrus、`getattr` 和 `__builtins__` 路径；这些都不能与一个正确聚合表达式混在一起
   获得通过。
6. **撤回只影响撤回前陈述。** 支持与冲突规则统一从最后一次明确“上句话错误”等撤回标记后
   开始判断，使“错误→撤回→完整改正”通过，同时继续阻断正确理由后的新反转。
7. **知识卡与正式题隔离。** 两张知识卡是项目原创，只包含通用公式、API 和解释边界；manifest
   使用 SHA-256 校验，正式题数字组合和答案指纹测试为零泄露。
