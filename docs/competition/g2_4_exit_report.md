## 关键设计决定

1. **概念题按教学目标分别取证。** 二项题分别检查固定次数、独立性、二分类、同概率、整数
   支持集、`np` 计算和期望的长期平均含义，避免只复述“二项分布”就获得通过。
2. **连续分布解释不再使用语义不等价的 OR。** CDF 作差、PDF 是密度、连续点概率为 0 和
   正态支持集为全部实数是四个独立必需组；“选择模型不等于证明现实适配”不能替代支持集证据。
3. **表面正确不能覆盖后续反转。** 通用撤回机制只接受最后一次撤回之后重新给出的完整证据；
   三题还覆盖独立性、参数角色和正态支持集的常见反向词形，并保留明确否定错误观点的保护。
4. **SciPy 调用采用精确 AST 合同。** 接受位置、关键字、混合参数、`stats`/`scipy.stats`
   两条明确路径和简单变量传递；拒绝错 `k/n/p`、CDF、PDF、随机抽样、额外参数、大小写错误、
   硬编码和与最终结果断开的正确调用。
5. **学生代码永不执行。** 判分只使用有长度、节点数和深度上限的 `ast.parse`；除直接危险
   调用外，还按顶层赋值顺序追踪 `runner=eval` 一类简单别名链，并允许调用前安全重绑定。
